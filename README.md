# Fractial

The NEW age of fractial

## Features

- Music Player
- Vertical Tabs
- Sleek Design

## Installation

Using the package manager of your choise install the dependencies by running, for this example npm will be used

```js
npm i
```

If your developing Fractial, use the dev server availible at `npm run dev`

If your using Fractial in Production, use `npm run start`
